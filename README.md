# شطرنج غیرممکن — راهنمای راه‌اندازی

سایت کاملاً استاتیک است (HTML/CSS/JS)؛ نیازی به PHP، پایگاه‌داده یا سرور خاصی ندارد.

## ۱) نصب Stockfish (قوی‌ترین ربات)
بدون این مرحله سایت کار می‌کند ولی با «ربات داخلی» (ضعیف‌تر). برای قدرت کامل، روی کامپیوتر خودت:

    python setup-engine.py

این اسکریپت Stockfish را از npm دانلود می‌کند، داخل `engine/` می‌گذارد و `js/config.js` را تنظیم می‌کند.
(دستی: بسته‌ی npm با نام `stockfish` را دانلود کن، فایل‌های `*lite-single*.js` و `*lite-single*.wasm` را در `engine/` بگذار و نام .js را در `js/config.js` بنویس.)

## ۲) آپلود
کل پوشه (شامل `engine/`) را در public_html هاستت آپلود کن. فایل `.htaccess` نوع `.wasm` را درست تنظیم می‌کند (Nginx: `application/wasm`).
بالای سایت نشان «Stockfish · قدرت کامل» باید سبز شود.

## تنظیمات
- `js/config.js`: زمان فکر ربات در سطح «غیرممکن» و مسیر موتور.
- `js/i18n.js`: همه‌ی متن‌ها (فارسی/انگلیسی).
- سطح‌ها: `js/engine.js` (آرایه‌ی LEVELS).

## مجوز
Stockfish تحت GPLv3 است؛ چون آن را در سایت توزیع می‌کنی، باید کد سایت را هم با همان مجوز در دسترس بگذاری (لینک «Stockfish» در پاورقی هست؛ یک لینک به سورس سایت هم اضافه کن).
